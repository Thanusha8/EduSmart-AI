## ✨ Features

- 🔐 Role-based authentication (Teacher & Student)
- 📄 Document upload and embedding generation
- 🔍 Vector search using Pinecone
- 🤖 AI-powered question answering using Groq LLaMA
- 📝 Automatic quiz generation and evaluation
- 📊 Quiz history and score tracking
- 💻 Streamlit-based frontend

## 🛠️ Tech Stack

- **Backend:** FastAPI
- **Frontend:** Streamlit
- **Vector Database:** Pinecone
- **Embeddings:** Google Gemini
- **LLM Model:** Groq LLaMA
- **Database:** MongoDB
- **Language:** Python

## 📋 Prerequisites

- Python 3.10 or higher
- MongoDB account (free tier)
- Pinecone account (free tier)
- Google Gemini API key
- Groq API key
